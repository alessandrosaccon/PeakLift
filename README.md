# PeakLift

AI-powered fitness tracking app for iOS.

## Overview

PeakLift is an iOS application that combines:

- workout tracking
- fitness analytics
- AI coaching
- Apple ecosystem integration

## Tech Stack

- Swift
- SwiftUI
- SwiftData
- CloudKit
- HealthKit
- Vision Framework
- AI APIs
